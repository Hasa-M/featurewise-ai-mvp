# Featurewise

Featurewise is a **pre-development quality and readiness tool** for product teams.

It helps Product Managers, Product Designers, Business Analysts, and other stakeholders review a feature **before it is handed over to development**.

Featurewise does not primarily generate specifications. Instead, it analyzes the information that already exists — such as feature descriptions, requirements, acceptance criteria, designs, documentation, files, and relevant source code — and identifies issues that could create problems during implementation.

It focuses on detecting things such as:

- missing information;
- ambiguous requirements;
- inconsistencies between different sources;
- undefined edge cases or states;
- hidden product decisions left to developers;
- requirements that are difficult to verify or test;
- gaps between the proposed feature and the existing product.

For each finding, Featurewise should explain:

- **what is wrong or missing;**
- **why it matters;**
- **where the issue comes from;**
- **how it could be resolved quickly and practically.**

The goal is simple:

> **Find expensive ambiguity before development starts.**

Featurewise is intended to act as a quality layer between **product intent and implementation**.

In the future, this layer could support both human development teams and automated workflows where PRDs, technical specifications, and software are increasingly generated by AI systems.

## Core idea

**Product context → Featurewise analysis → Findings & suggested resolutions → Ready for development**
